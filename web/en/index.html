Everything you do with Claude Code, in plain sight.

The same sessions you use in the terminal, with an interface made for reading and working at your own pace.

Chat with Claude Code

Start new sessions or pick up any of them. Clear permissions, message queue, background tasks and attached images or files.

History and search

All your local conversations, with a live viewer and global search across every project with Ctrl K.

Usage and limits

An always-visible 5-hour window meter, a daily chart and breakdowns by model and by project.

Git and files

Repository branch and changes, a files panel with preview and diff against HEAD, and Markdown export.

Built-in terminal

Open the project shell or claude --resume in tabs, without leaving the app.

Always up to date

It downloads new versions in the background and updates with one click, without going through the installer again.

Made for the keyboard.

Everything important is one shortcut away.

  • Ctrl K Search every session
  • Ctrl U Usage and limits
  • Ctrl ` Terminal
  • Ctrl , Settings
  • Ctrl F Search the conversation
  • Esc Stop the response

Your data stays on your computer.

  • Local only. It reads the sessions Claude Code saves in your user folder and doesn't send them anywhere.
  • No credentials. It uses Claude Code with the account you sign in with. It never asks for, reads or stores keys.
  • No telemetry. No analytics, no tracking. The only thing it checks on its own is whether there's a new version.

You don't have to take our word for it: the code is on GitHub for anyone to review.

Get started in three steps.

  1. 1

    Your Claude account

    Use Claude Code with your Claude account. If you haven't signed in yet, OpenClod walks you through it the first time you open it.

  2. 2

    Download OpenClod

    Open the installer. If you already have a version, it detects it and asks before updating it.

  3. 3

    Choose a project

    Your sessions show up on their own. Open one or start a new one.
